## The Hydro-Kinetic Monolith Design System

| Token | Hex / Value | Role | Ratio |
|---|---|---|---|
| **Canvas Void** | `#050505` | Primary background canvas | ~85–92% |
| **Vessel Surface** | `#111115` / `#111111` | Soft-rounded glass cards (`blur(24px)`) | — |
| **Primary Type** | `#FFFFFF` | Headlines, primary text | ~5–10% |
| **Secondary Type** | `#A1A1AA` | Editorial body narrative | — |
| **Telemetry** | `#666670` | Labels, coordinates, code | — |
| **Kinetic Accent** | `#CCFF00` | Bioluminescent chartreuse node | **Strictly $\le$ 5%** |

### Prohibited Palette
* **Zero Solar Brass (`#E5A93C`)**, warm gold, cyan, or purple neon.
* **Zero light-mode / white page backgrounds.**

### Typography Engine
* **Display / Headlines:** `Kanit` Bold (700), uppercase, `+0.05em` tracking.
* **Editorial Narrative Body:** `Inter` (300/400/500/600), `1.65` line-height.
* **Telemetry & Coordinates:** `JetBrains Mono` (500), uppercase (`// 01 // TAG`).
